## 명세가 비어 있는 장표

S01, S06, S11, S18, S25, S30은 이미지가 있지만 본문은 “명세 내용이 없습니다.”이다. 각각 묶음 진입·설정 화면으로 다루고, 이미지에서 확인되지 않는 동작은 별도 제안으로 기록한다. S06·S18·S30의 이미지가 로그인 화면인 점도 해당 영역의 실무 화면으로 확정하지 않는다.

## 상태 갱신

레지스트리의 status는 미매핑 → 설계 → 구현 중 → 검증 → 완료로 관리한다. 완료 시 실제 경로, 검증 근거, 남은 외부 연동을 별도 필드로 기록한다. 데이터 저장, 서버 권한 검사, 실패·재시도, 다음 기능에 전달할 데이터까지 확인해야 완료로 변경한다.
