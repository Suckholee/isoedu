# 회의 반영 1차: 회사 소속·복수 프로젝트·구비서류와 준비 일정

기록일: 2026-10-19. 근거: 사용자가 제공한 회의 전사문(회의 일자 미확인)과 “진행하고자 해” 지시. 회의의 전체 사업 아이디어를 확정 요구사항으로 간주하지 않고, 합의한 첫 개발 묶음만 구현한다. 플랫폼 표시명은 어니스톤을 유지한다.

## 범위와 기능 연결

- S02/S03/S04: 기존 로그인 사용자 → 회사 관리자가 전달한 소속 신청 코드 → 승인 대기 → 관리자의 열람/편집 승인 → 회사 접근. 회사명만으로 기존 회사에 합류하지 않는다. 코드는 요청만 허용하고 조회 권한을 주지 않는다. 이 화면의 OWNER는 회사 자료 관리 권한이며 법적 대표자 인증 완료를 의미하지 않는다.
- S04 → S11/S17/S05: 소속 해제는 멤버십을 비활성화하고 해제 이력과 감사 로그를 보존한다. 프로필의 이전 회사 ID가 남아 있어도 비활성 멤버십을 우회할 수 없다. 회사 자료는 삭제하지 않는다. 심사원도 해당 회사에 배정된 멤버십이 있어야 조회할 수 있다. 기존 플랫폼 ADMIN의 운영 권한은 유지한다.
- S03 → S07/S12/S13: 기존 거래처에 복수 프로젝트를 생성한다. 신규 거래처는 명시적으로 선택한 경우에만 별도 회사 공간으로 등록한다. ISO 프로젝트는 복수 규격, 기업 인증/지원사업/종합 컨설팅은 사용자가 확인한 서류명을 입력한다. 사업자번호·대표자명·직원수·심사원·목표일을 임의로 채우지 않는다.
- S12/S13 → S11/S17: 생성 시점의 구비서류 key/title/standard/source_version을 보존하고, 회사 내 실제 문서 document_id를 연결한다. 연결됐다는 이유로 작성·승인·심사 적합을 완료 처리하지 않는다. 기존 ISO 기준 목록은 최신 판본이나 공식 요건으로 새로 검증한 자료가 아니다. 발급받은 인증서 자체는 준비서류 자동 목록에서 제외한다.
- S07/S13 → S05/S23: 내부 목표일과 준비 업무별 날짜를 검토 후 저장한다. 초기 제안은 내부 목표일 30/14/3일 전이며 수정 가능하고 미정도 허용한다. 법정·공식 심사기간이 아니다. 공식 신청 마감은 기존 업무의 official_due_date로 별도 관리한다. 목표일을 바꿨다고 사용자가 수정한 날짜를 자동 덮어쓰지 않는다.
- 프로젝트 → 기존 내 업무 목록/달력: work_tasks.project_id로 연결하며 URL company/project/task/view로 전달한다. 거래처 변경 시 이전 프로젝트·문서·업무 선택을 제거한다. 회사/프로젝트/문서 간 불일치는 서버에서 거부한다. 사이드바 접힘과 기존 필터를 유지한다.

## 저장·권한 계약

`supabase/company_projects_migration.sql`은 platform_migration.sql, work_tasks_migration.sql 이후 실행한다. 비활성 멤버십·소속 요청/관리자 승인 RPC·프로젝트 구비서류·업무 프로젝트 연결을 추가한다. 삭제나 기존 회사/파일 이관을 하지 않는다. 신규 프로젝트+구비서류+업무는 하나의 트랜잭션으로 저장한다. 사용자별 requestId는 재시도 중복을 방지하고, 동일 ID로 다른 내용을 저장하려 하면 거부한다. 부분 실패는 새 회사 생성까지 롤백한다.

회사 관리자는 소속 요청자의 이름과 이메일을 확인하고 열람/편집으로 승인한다. 자기 소속 해제와 OWNER 소속 해제/대표자 이전은 이 기능에서 막는다. 코드 갱신 RPC는 준비했으나 UI 갱신 기능은 이번 범위에 포함하지 않는다. 원격 이메일 초대 발송·대표자/사업자 실명 확인은 미구현이다.

파일은 신규 서명URL 발급 대신 `/api/vault-file`을 통해 사용자 확인, 회사·문서 RLS 확인, Storage의 사용자 토큰 검사를 거쳐 스트리밍한다. PDF Range와 타입/크기 헤더를 전달하고 캐시는 private/no-store로 제한한다. 링크에 인증 토큰을 넣지 않는다. 소속 해제 뒤 새 파일 요청은 차단되지만 이미 로드되거나 다운로드한 사본을 회수할 수 없고, 이전 배포에서 발급된 서명URL은 원래 만료까지 유효할 수 있다. 화면 복귀 시 접근 가능한 회사·프로젝트를 다시 조회하고 해제된 거래처 선택/업무 상세를 제거한다. 실시간 강제 화면 삭제/푸시 로그아웃은 구현하지 않았다.
