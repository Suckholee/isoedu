## 기존 자료와 권한

공유 Drive 270개 메타데이터 중 공통 참고 69원본을 분류했다. 빈 양식 후보21, 작성사례21, 안내20, 기타2, 미판정5다. 회사별·소속 확인대기 201개는 메타데이터만 검토했다. 작성사례·공통 안내·미판정 자료는 빈 양식으로 허용하지 않는다. 기존 원본·회사 연결은 변경하지 않는다. 개인/기업 자료를 공개 정적 파일로 복사하지 않으며 공개 폴더는 정부·기관이 공개한 빈 양식·안내서로 한정한다.

S03 회사·프로젝트 → S11/S16 자료 → S12 양식 → S13 사실·계획 → S14 초안 → S15 편집·검토 → S17 버전 저장을 유지한다. 회사·프로젝트·문서 ID, 양식 ID/key/연도/차수/SHA256/확인일/문항/작성조건/문서종류/제출방식/출처범위를 저장 문서에 인계한다. 서버가 등록된 본문·버전·사업유형을 대조하고 작성방식은 서버 값으로 덮어써 클라이언트 변조를 무시한다. 회사 근거는 동일 회사·기존 권한 검사, 확인대기 제외, 생성 후 권한 재확인, 동시수정 보호를 유지한다.

## 기능 범위와 검증

벤처 안내와 영상 대본은 필수 문항 누락·순서 변경을 거절한다. 영상은 실제 대표자/과제책임자의 현장 촬영용 대본·장면·추천 시간을 준비하며 실제 영상 촬영·제출 기능은 아니다. 온라인 초안은 신청 시스템으로 옮길 자료이며 공식 접수가 아니다. 한글 원본의 페이지 배치를 그대로 재현하거나 최종 제출 쪽수를 자동 보증하지 않는다. 기존 Word 내보내기와 글·표·그래프·도식·이미지 편집을 사용한다.

전체 테스트 222개 통과, 배포용 빌드 성공. 30종의 서버 생성·저장 인계는 모의 AI 응답으로 검증했다. 원본 26개 모두 빌드 서버 HTTP200·크기·SHA256 일치. 실제 화면에서 빈 양식/안내/촬영 대본 구분, 원문 읽기, 확인 전 작성 차단, 확인 후 활성화, 유형 전환 시 양식 초기화·사업 설명 보존, 미확보 범위 펼침을 확인했고 브라우저 오류 0. 임시 검증 화면 제거 및 최종 빌드 목록 제외 확인. 운영 배포·실제 운영 문서 저장·30종 전체 실제 AI 생성은 미수행.
