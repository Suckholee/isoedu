## 화면 내부 동작

- 인증 관리: 규격 선택·구비 상태 필터는 같은 화면의 내용을 바꾼다. AI 양식 버튼은 초안 저장이 필요한 작업이며 DB 연동 검증 미완료.
- 문서 관리: 예시 선택은 우측 미리보기 변경, 복사는 클립보드 동작. 편집기 진입은 회사·인증된 저장 조건 확인 필요.
- 알림 센터: 전체·만기 경과는 목록 필터. 외부 알림 발송·읽음 저장 없음.
- 로그인·가입: 탭 이동과 닫기 확인. 계정 생성·인증 제출은 실행하지 않았다.
- 문서 등록·연결: 열기·닫기 확인. 실제 DB 쓰기·첨부 업로드·문서 편집 저장은 미검증.
- 전용 심사 예약 미구현. 리스크 차트의 요약 수치는 시연 데이터.

정부지원사업 목록 코드는 있으나 현재 주 메뉴에서 접근할 수 없으므로 캡처 가능한 실제 페이지로 표기하지 않았다. 기업 프로필 기반의 맞춤 필터는 예정 흐름으로 분리했다.
